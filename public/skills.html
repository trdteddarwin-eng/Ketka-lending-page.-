FAQ

What is a Claude Code skill?

+

A skill is a single .md file that tells Claude Code exactly how to run a complex pipeline — step by step, tool by tool. You drop it in your project, type a slash command, and Claude executes the entire workflow autonomously. Think of it as a production-grade SOP that an AI agent follows perfectly every time.

What do I need to get started?

+

Claude Code installed on your machine, plus the API keys listed on each skill card. Most skills need an OpenRouter API key (for LLM calls) and one or two service-specific keys. Each skill's "What you need" section tells you exactly which accounts to set up.

How do I install a skill?

+

After purchase, you receive a .md file. Put it in your .claude/agents/ directory. Open Claude Code and type the slash command (included in the file). Claude reads the instructions and runs the entire pipeline. No dependencies to install, no config files to edit.

Can I customize the skills?

+

Yes — everything is in the .md file in plain English. Change the output style, adjust pipeline steps, add new features, swap API providers. It's your file. The skill is a starting point that already works out of the box, but you own it completely.

What if I need help?

+

Reply to your purchase receipt email and we'll get back to you within 24 hours. If you need something more hands-on — custom skill development, pipeline debugging, or a full walkthrough — book a call and we'll sort it out live.
